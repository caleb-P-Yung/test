# Blind Filter Mod

This mod adds a custom Curse Enchantment that simulates the blindness visual effect without the mechanical debuff.

### Features
- **Curse of Blindness**: A new treasure enchantment for helmets.
- Visual tunnel-vision overlay applied when a cursed helmet is worn.
- Does NOT affect movement or interaction (purely visual).

### How to obtain
Since it is a Curse, you can find it in loot chests (like Ancient Cities or Bastions) or through fishing/trading, similar to Curse of Binding.
